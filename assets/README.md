# Assets

Tab-effect screenshots for storefronts and the READMEs. Rendered from the
plugin's actual ring geometry (outer radius 50, stroke 26, 34-degree trailing
gap while running, palette `#5686FE` / `#F59E0B` / `#22C55E`) at 128 px for
readability; the ring-hole center shows a simplified whale silhouette standing
in for the document's original favicon.

- `running.png` — blue ring with the trailing gap, spinning while work runs.
- `pending.png` — amber complete ring, waiting on the user.
- `done.png` — green complete ring, finished.

Regenerate with `pwsh -File scripts/render-screenshots.ps1`.
